# 럭키팡 (LuckyPang) - 수학 약수와 배수 편 🎰

> **완전 무서버(Zero-Config) PeerJS + WebRTC P2P 기반 실시간 교실 퀴즈 게임**  
> 초등학교 5학년 수학 '약수와 배수' 단원을 재미있는 퀴즈와 럭키 추첨 레이스로 즐길 수 있는 교육용 웹 애플리케이션입니다.

---

## 🌟 핵심 특징

1. **완전 무서버 (Zero-Config) P2P 아키텍처**
   - 별도의 유료 백엔드(Firebase, Supabase, PartyKit 등)나 데이터베이스가 전혀 필요하지 않습니다.
   - **PeerJS 기본 공용 시그널링 서버(`0.peerjs.com`)**와 기본 설정을 활용하여 교사와 학생 브라우저가 직접 P2P(WebRTC DataChannel)로 통신합니다.
   - 별도의 유료 TURN 릴레이 서버를 두지 않는 구조이므로, **학교망 환경(엄격한 방화벽, 대칭형 NAT 등)에 따라 일부 접속 실패가 발생할 수 있습니다.** (접속 실패 시 안내 모달 및 재시도 지원)

2. **교사 권위적 전담 채점 & 동기화**
   - **교사 브라우저(Host)**가 퀴즈 생성, 학생 답안 공정 채점, 라운드 진행, 1초 주기 실시간 보드(`board`) 브로드캐스트, 최종 럭키 추첨 미션 보너스 계산을 전담합니다.
   - 학생 화면에서의 임의 조작이나 네트워크 지연으로 인한 부정행위를 원천 방지합니다.

3. **원클릭 Vercel 배포 지원**
   - 환경변수(`Environment Variables`) 설정이 **0개** 필요합니다.
   - 깃허브 저장소를 Vercel에 연결하고 **Deploy** 버튼만 누르면 바로 전 세계 어디서나 서비스가 가능합니다.

## 🛠 기술 스택

- **Frontend**: Next.js 16 (App Router), React 19, TypeScript
- **Styling**: Tailwind CSS v4, Lucide React (아이콘)
- **Networking**: WebRTC P2P, PeerJS (`peerjs`, 기본 공용 서버 `0.peerjs.com`)
- **Utilities**: `qrcode.react` (학생 입장용 QR코드 생성)

## 🚀 빠른 시작 (로컬 실행)

### 1. 패키지 설치
```bash
npm install
```

### 2. 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:3000`으로 접속합니다.

### 3. 프로덕션 빌드
```bash
npm run build
npm run start
```

1. 본 저장소를 개인 GitHub 계정으로 푸시(Push) 또는 포크(Fork)합니다.
2. [Vercel](https://vercel.com)에 로그인한 후 **Add New Project**를 클릭합니다.
3. 해당 GitHub 저장소를 선택합니다.

## 🎮 교실 수업 활용 가이드

### 1. 교사 (방 만들기)
1. 메인 화면에서 **"선생님 방 만들기"**를 선택합니다.
2. 문항 수(6, 12, 18, 24, 30문항), 난이도(쉬움, 보통, 어려움, 골고루), 문제 유형 비율을 선택합니다.
3. 전자칠판이나 빔프로젝터에 생성된 대기실 화면(6자리 방 번호 및 대형 QR 코드)을 띄웁니다.
4. 학생들이 모두 입장하면 **"게임 시작"** 버튼을 누릅니다.

### 2. 학생 (참여하기)
1. 크롬북, 노트북 또는 태블릿 카메라로 교사 화면의 **QR 코드를 스캔**하거나, 메인 화면에서 **6자리 방 번호**와 **이름(닉네임)**을 입력하고 입장합니다.
2. 문제가 시작되면 제한시간 내에 약수·배수 문제를 풀고 번호를 선택합니다.
3. 문제를 맞히면 점수와 함께 **럭키 티켓**이 지급됩니다!

### 3. 피날레: 럭키 추첨 레이스
1. 모든 퀴즈 라운드가 종료되면 획득한 티켓으로 **럭키 추첨 머신**이 가동됩니다.
2. 뽑은 4자리 행운 번호가 오늘의 **수학 미션**(예: 4의 배수 포함, 7의 배수 포함, 약수의 합 10 이상 등)을 달성할 때마다 최대 1,000점의 역전 보너스 점수가 추가됩니다.
3. 최종 1, 2, 3위 및 전체 순위가 시상대 연출과 함께 발표됩니다.

## 📁 프로젝트 구조

```
luckypang-peerjs-turn/
├── app/
│   ├── layout.tsx              # 전역 레이아웃 및 폰트
│   ├── page.tsx                # 랜딩 및 로비 (방 만들기/입장)

│       ├── page.tsx            # 대기실, 퀴즈, 럭키추첨, 결과 통합 화면
│       └── answer-key/         # 교사용 정답지/해설 뷰

│   └── LuckyDrawMachine.tsx    # 럭키 추첨기 UI 및 미션 판정 컴포넌트
├── lib/
│   ├── mathEngine.ts           # 약수/배수 문제 생성기 및 미션 보너스 계산 엔진
│   └── party.ts                # 학생 로컬 경기 기록 관리 (LocalStorage)
└── src/
    └── net/
        └── room.js             # PeerJS 기반 HostRoom / GuestRoom 네트워크 계층
```
